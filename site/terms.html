What Reminth is

Reminth is a free launcher for Minecraft: Java Edition on Windows. It downloads the official game files from Mojang, sets up the Fabric mod loader, and starts the game using your own signed-in Microsoft account.

You need your own legitimate, paid Minecraft: Java Edition licence. Reminth does not include the game, does not distribute a copy of it, and provides no way to play without owning it. If you don't own Minecraft, Reminth is of no use to you.
